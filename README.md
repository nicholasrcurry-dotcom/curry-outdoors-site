# Curry Outdoors — public site

Two static pages, deliberately dependency-free, served by GitHub Pages:

- `index.html` — the **Support URL** App Store Connect requires
- `privacy.html` — the **Privacy Policy URL** it also requires

The policy's source of truth is `docs/PRIVACY.md` in the app repo. If the app
starts collecting something new, change it there, mirror it here, and update the
App Privacy answers in App Store Connect — Apple compares declarations against
observed behaviour.

This repo is public so GitHub Pages can serve it for free. It contains nothing
but these pages.
